# Sudoku Open Lab

A web-based Sudoku game designed to make open-source contribution accessible to students through meaningful, beginner-friendly issues.

## About the Project

Sudoku Open Lab is a community-driven project to build an interactive Sudoku game using modern web technologies. Alongside developing the game, the project aims to help students learn Git, GitHub, collaborative development, and open-source contribution through practical experience.

## Objectives

- Build a simple, accessible, and responsive Sudoku web application.
- Provide opportunities to contribute to real software projects.
- Help students learn Git, GitHub, branching, commits, and pull requests.
- Encourage collaboration, code reviews, debugging, and testing.
- Create a welcoming environment for first-time contributors.

## Planned Features

The initial version is expected to include:

- Interactive 9×9 Sudoku grid.
- Number input and cell editing.
- Sudoku row, column, and 3×3 box validation.
- Multiple difficulty levels: Easy, Medium, and Hard.
- Erase, reset, and new-game controls.
- Responsive layout for desktop and mobile devices.

Possible future enhancements include hints, a timer, pencil notes, undo/redo, dark mode, keyboard navigation, puzzle generation, and automated testing.

## Tech Stack

- **React** — UI components and application interface.
- **Vite** — Development server and build tooling.
- **JavaScript** — Game logic and interactions.
- **CSS** — Styling and responsive design.
- **Git and GitHub** — Version control and collaboration.

The initial version is planned as a client-side application, without requiring a backend or database.

## Open-Source Contribution

The project is intended to be beginner-friendly. Contributors may help with:

- UI and responsive design improvements.
- Bug fixes and Sudoku validation.
- Accessibility and keyboard controls.
- Testing and code quality.
- Documentation and setup instructions.
- New game features and enhancements.

Contributors will be encouraged to work through GitHub issues, create branches, make meaningful commits, and submit pull requests for review.

## Project Roadmap

1. **Planning:** Finalise requirements and initial UI design.
2. **MVP Development:** Build the core Sudoku game and validate its functionality.
3. **Repository Setup:** Add contribution instructions and beginner-friendly issues.
4. **Community Contributions:** Invite students to work on issues and submit pull requests.
5. **Continuous Improvement:** Review contributions, fix bugs, and introduce additional features.
